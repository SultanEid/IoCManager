name: ioc-product-guardrail
description: Use for any task that may expand scope, rename product concepts, add AI claims, or reintroduce CTI-platform behavior. Do not use for simple syntax fixes.
---

1. The product is a serious IoC operations platform with a narrow intelligence assist layer.
2. Reject changes that move the product toward general CTI, actor mapping, campaign analysis, or graph-first workflows.
3. Prefer operational workflows: ingest, normalize, enrich, triage, propose, approve, deploy, monitor, rollback.
4. Frontend changes must preserve the current visual identity.
5. AI changes must be grounded, auditable, and capable of abstaining.
6. If a request conflicts with these rules, propose the smallest compliant alternative.
