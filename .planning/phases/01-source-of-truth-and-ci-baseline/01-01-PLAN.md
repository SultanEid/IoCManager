# Plan 01-01: Onboarding and canonical source docs

<objective>
Make the active product root obvious to humans and agents by giving `README.md`, `AGENTS.md`, and `Workspace/README.md` clear, non-overlapping responsibilities. This plan covers GOV-01 and decisions D-01, D-02, D-12, D-13, D-14, and D-15.
</objective>

<context>
- Phase context: `.planning/phases/01-source-of-truth-and-ci-baseline/01-CONTEXT.md`
- Roadmap: `.planning/ROADMAP.md`
- Requirements: `.planning/REQUIREMENTS.md`
- Research: `.planning/phases/01-source-of-truth-and-ci-baseline/01-RESEARCH.md`
- Existing guidance: `AGENTS.md`, `Workspace/README.md`, `Workspace/Project/backend/README.md`
</context>

<must_haves>
<truths>
- D-01: `Workspace/Project/` is the only active application root for new product work.
- D-02: `src/IocManager.Web` is removed/decommissioned and must not be presented as an active surface.
- D-12: Use a small combination of onboarding surfaces, each with a clear job.
- D-13: `AGENTS.md` guides coding agents and future GSD work.
- D-14: `Workspace/README.md` guides developers to the canonical stack and active entry points.
- D-15: Root `README.md` concisely routes humans to the canonical workspace and validation commands.
</truths>
<acceptance>
- `README.md` states that the active app is under `Workspace/Project/` and points to `Workspace/README.md`, `AGENTS.md`, and validation docs.
- `AGENTS.md` keeps agent-focused rules and explicitly says not to reintroduce `src/IocManager.Web`.
- `Workspace/README.md` remains the developer orientation for backend, frontend, AI sidecar, scripts, and docs.
- No document claims `Archive/`, `AI_Project/`, `tmp/`, backups, result folders, screenshots, logs, or `src/IocManager.Web` are active product roots.
</acceptance>
</must_haves>

<threat_model>
<threat id="T-01-01" severity="medium">
Stale or ambiguous onboarding can send future agents to removed roots or archived code, causing unsafe edits or reviews in the wrong surface.
</threat>
<mitigation>
Make root and workspace docs explicitly name `Workspace/Project/` as the active root, state that `src/IocManager.Web` is decommissioned, and keep archive/generated folders as reference-only.
</mitigation>
<verification>
Search updated docs for `Workspace/Project`, `src/IocManager.Web`, and active/reference wording. Confirm the removed root is only mentioned as decommissioned.
</verification>
</threat_model>
